# RTD releases

The RTD fork has not launched a public Mainnet. This file does not list the historical Sui release dates or tags as RTD releases.

When an RTD network is published, record only releases built from this fork. Each entry should include its source commit, binary checksums, target RTD chain identifier and genesis, supported protocol version, network operator, and verification results. A future RTD Mainnet will not expose JSON-RPC.
