# Security policy

This fork has not announced an RTD bug bounty program, reward schedule, public
security mailbox, or third-party reporting partner. Do not treat bounty terms
or contact addresses copied from upstream documentation as RTD policy.

Please do not disclose a suspected vulnerability or exploit details in a public
issue. If the repository's GitHub **Security** tab offers private vulnerability
reporting, use that channel. Otherwise, contact the repository maintainers to
arrange a private reporting channel before sharing details.

The maintainers must publish a verified reporting address, response process,
and any bounty terms before announcing a production RTD network.
