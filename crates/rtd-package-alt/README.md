Move package management
=======================

This is the rtd adapter for the (new) package management system; it replaces the `rtd-package-management` crate.

It is a thin wrapper around the `move-package-alt` crate to fill in the rtd-specific details.

See also the [user guide][guide] in this repository. RTD has no published documentation site yet.

[guide]: /docs/content/develop/manage-packages/move-package-management.mdx
