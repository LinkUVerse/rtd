:::caution RTD deployment status

The upstream Move Registry uses a name registry and chain-specific package IDs. A source-level resolver in the RTD fork does not establish an RTD registry or public MVR service.

RTD has not launched Mainnet. Do not use upstream Sui addresses, package IDs,
network settings, tokens, or service endpoints as RTD configuration.

:::

This page is retained as a navigation placeholder for the upstream Move Registry topic.
Before publishing an RTD integration guide, deploy the required services and
contracts on an RTD network, verify end-to-end behavior, and publish the
actual RTD-specific endpoints and object IDs.
