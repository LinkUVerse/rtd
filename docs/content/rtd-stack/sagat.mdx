:::caution RTD deployment status

Sagat is an upstream Sui ecosystem multisig application. The previous
forked page pointed to unverified RTD-hosted sites, APIs, and SDKs. No
RTD Sagat deployment or public service has been verified. RTD has not
launched Mainnet.

:::

RTD protocol multisignature support is described in the
[multisig guide](/develop/transactions/transaction-auth/multisig).
A Sagat-style application requires an RTD-compatible API, frontend,
wallet integration, and transaction verification before documentation
can provide operational steps.
