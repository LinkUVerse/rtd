:::caution RTD deployment status

SuiPlay0X1 is an upstream Sui ecosystem device and integration. No RTD-compatible device, wallet integration, or game platform has been verified.

RTD has not launched Mainnet. Do not use upstream Sui addresses, package IDs,
network settings, tokens, or service endpoints as RTD configuration.

:::

This page is retained as a navigation placeholder for the upstream SuiPlay0X1 topic.

contracts on an RTD network, verify end-to-end behavior, and publish the
actual RTD-specific endpoints and object IDs.
