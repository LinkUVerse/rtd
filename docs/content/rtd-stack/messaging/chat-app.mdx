:::caution RTD deployment status

The upstream encrypted messaging examples depend on Seal, Walrus, a relayer, and Move packages. No complete RTD deployment or compatible public messaging service has been verified.

RTD has not launched Mainnet. Do not use upstream Sui addresses, package IDs,
network settings, tokens, or service endpoints as RTD configuration.

:::
