The Rtd Rust SDK provides Rust wrappers for interacting with Rtd networks. Two Rust SDK crates are available:

| **Crate** | **Repository** | **Status** | **Use when** |
|---|---|---|---|
| [`rtd-rust-sdk`](https://github.com/LinkUVerse/rtd-rust-sdk) | [LinkUVerse/rtd-rust-sdk](https://github.com/LinkUVerse/rtd-rust-sdk) | **Current** | Building new Rust integrations. Uses [GraphQL RPC](/develop/accessing-data/graphql/graphql-rpc) and [gRPC](/develop/accessing-data/grpc). |
| [`rtd-sdk`](https://github.com/LinkUVerse/rtd/tree/main/crates/rtd-sdk) | [LinkUVerse/rtd](https://github.com/LinkUVerse/rtd/tree/main/crates/rtd-sdk) | **Legacy** | Maintaining existing integrations that depend on this crate. |

For new projects, use [`rtd-rust-sdk`](https://github.com/LinkUVerse/rtd-rust-sdk). It is the actively maintained Rust SDK with support for the current Rtd API surface.

## Legacy `rtd-sdk` crate

The legacy SDK crate lives in the [`crates/rtd-sdk` directory](https://github.com/LinkUVerse/rtd/tree/main/crates/rtd-sdk) of the main Rtd repository. It is forward and backwards compatible with `rtd-rust-sdk`.

### Installation

Add the crate to your `Cargo.toml`:

```toml
[dependencies]
rtd-sdk = { git = "https://github.com/LinkUVerse/rtd.git", package = "rtd-sdk" }
```
