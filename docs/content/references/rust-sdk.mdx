The [dedicated Rust SDK source](https://github.com/LinkUVerse/rtd-rust-sdk) and the main repository's [`crates/rtd-sdk`](https://github.com/LinkUVerse/rtd/tree/main/crates/rtd-sdk) are separate codebases. Inspect their manifests and APIs before choosing one. The older crate may be useful during migration, but this page does not claim binary or API compatibility with the dedicated SDK.

For an application that connects to an RTD network, use a source revision that matches its protocol. Configure its gRPC or GraphQL client with an endpoint operated for that chain, and verify genesis and chain ID. No public RTD GraphQL endpoint is established by the existence of the SDK.

```toml
[dependencies]
rtd-sdk = { git = "https://github.com/LinkUVerse/rtd.git", package = "rtd-sdk" }
```

The dependency above is a source example for the older crate. Pin a reviewed commit in a real application and test against the intended RTD network. See [SDK comparison](/references/sdk-comparison).
