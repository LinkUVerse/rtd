Rtd provides developer kits that act as wrappers for the Rtd API. The Rtd community broadens the code coverage with its own set of developer kits targeting the Rtd blockchain. 

## Rtd SDKs

:::caution 

`rtd-rust-sdk` does not support JSON RPC. If you need JSON RPC access, use the [legacy Rust SDK](/references/rust-sdk). It is forward and backward compatible.

<ImportContent source="json-rpc-deprecation" mode="snippet" />

:::

<Cards>
<Card title="dApp Kit" href="https://sdk.linkuverse.com/dapp-kit">
    A web frontend SDK that interacts with the Rtd API. It is available as an NPM package.
</Card>
<Card title="Rust SDK" href="https://github.com/LinkUVerse/rtd-rust-sdk">
    SDK configuration and examples of using the Rtd API with Rust, using the `rtd-rust-sdk` crate.
</Card>
<Card title="Legacy Rust SDK" href="/references/rust-sdk">
    Supports JSON RPC access. It is forward and backward compatible.
</Card>
<Card title="TypeScript SDK" href="https://sdk.linkuverse.com/typescript">
    TypeScript SDK for integrating Rtd in your TS apps.
</Card>
<Card title="zkSend SDK" href="https://sdk.linkuverse.com/zksend">
    zkSend SDK to enable you to incorporate Stashed functionality.
</Card>
</Cards>

## Community SDKs

:::info 

While the community projects are expertly developed, their maintenance and community support vary. You might want to research a project's history and support level before committing to using its utilities. 

:::

<Card title="dApp Kit (Vue)" href="https://github.com/RtdFansCN/suiue">
