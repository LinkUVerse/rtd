Rtd repositories are open source and welcome community contributions.

This page describes how to contribute to Rtd, and provides additional information about participating in the Rtd community.

## Join the community {#join-the-community}

To connect with the Rtd community, join our [Discord](https://discord.gg/rtd).

## Open issues {#open-issues}

To report an issue with Rtd, [create an issue](https://github.com/LinkUVerse/rtd/issues/new/choose) in the GitHub repo. Click **Get started** to open a template for the type of issue to create.

## Fork Rtd to contribute {#fork-rtd-contribute}

To contribute to Rtd source code or documentation, you need only a GitHub account. Follow these steps to submit a contribution:

1. Fork the [LinkUVerse/rtd](https://github.com/LinkUVerse/rtd) repository by clicking **Fork** on the GitHub page.
2. Clone your fork locally:
   ```sh
   $ git clone https://github.com/YOUR_USERNAME/rtd.git
   ```
3. Create a feature branch from `main`:
   ```sh
   $ git checkout -b your-branch-name main
   ```
4. Make your changes and commit them with a descriptive message.
5. Push your branch to your fork:
   ```sh
   $ git push origin your-branch-name
   ```
6. Open a pull request from your branch to the `main` branch of [LinkUVerse/rtd](https://github.com/LinkUVerse/rtd/compare).

Always submit PRs to the `main` branch. See [Rtd Environment Setup](/references/contribute/rtd-environment) for additional instructions on configuring your local environment.

## Contribute through the Rtd Improvement Proposal (SIP) process {#SIP}

The Rtd Network is an open source, decentralized, and permissionless protocol that welcomes community contributions. If you have an idea regarding a core protocol upgrade, submit a [Rtd Improvement Proposal (SIP)](https://sips.rtd.io). For more information on the SIP process, see [Contribute to Rtd through SIPs](https://blog.rtd.io/rtd-improvement-proposals-sips/).
