The cheat sheet highlights common Rtd CLI commands.

This page is the RTD CLI reference. The PDF inherited from upstream contains
`sui` commands and is retained separately under its original Sui name; it is
not an RTD CLI cheat sheet.

## Addresses and aliases

<table class="w-100">
	<thead>
		<tr>
			<td>Command</td>
			<td>Description</td>
		</tr>
	</thead>
	<tbody>
		<tr>
			<td class="w-2/3">`rtd client active-address`</td>
			<td class="w-1/3">Get the active address</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client addresses`</td>
			<td class="w-1/3">List the addresses, their aliases, and the active address</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client new-address ed25519`</td>
			<td class="w-1/3">Create a new address with ED25519 scheme</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client new-address ed25519 MY_ALIAS`</td>
			<td class="w-1/3">Create a new address with ED25519 scheme and alias</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client switch --address ADDRESS`</td>
			<td class="w-1/3">Make this the active address (accepts also an alias)</td>
		</tr>
		<tr> 	
			<td class="w-2/3">`rtd keytool convert PRIVATE_KEY`</td>
			<td class="w-1/3">Convert private key in Hex or Base64 to new format (Bech32 encoded 33 byte flag || private key starting with "rtdprivkey")</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd keytool generate ed25519`</td>
			<td class="w-1/3">Generate a new keypair with ED25519 scheme and save it to file</td>
		</tr>
		<tr> 	
      <td class="w-2/3">`rtd keytool import INPUT KEY_SCHEME`</td>
			<td class="w-1/3">Add a new key to Rtd CLI Keystore using either the input mnemonic phrase or a Bech32 encoded 33-byte flag || privkey starting with "rtdprivkey"</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd keytool update-alias OLD_ALIAS NEW_ALIAS`</td>
			<td class="w-1/3">Update the alias of an address</td>
		</tr>
	</tbody>
</table>

## Faucet and gas

:::info Faucet availability

Use `rtd client faucet` only with a verified faucet for your configured RTD network. A local deployment can provide one. Public RTD faucets and Mainnet economics are not established by this repository.

:::

<table class="w-100">
	<thead>
		<tr>
			<td>Command</td>
			<td>Description</td>
		</tr>
	</thead>
	<tbody>
		<tr>
			<td class="w-2/3">`rtd client faucet`</td>
			<td class="w-1/3">Get a RTD coin from the faucet (Devnet and Localnet only)</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client faucet --address ADDRESS`</td>
			<td class="w-1/3">Get a RTD coin for the address (accepts also an alias)</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client faucet --url CUSTOM_FAUCET_URL`</td>
			<td class="w-1/3">Get a RTD coin from custom faucet</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client gas`</td>
			<td class="w-1/3">List the gas coins and total RTD balance for the active address</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client gas ADDRESS`</td>
			<td class="w-1/3">List the gas coins and total RTD balance for the given address (accepts also an alias)</td>
		</tr>
		<tr>
			<td class="w-2/3">`rtd client balance`</td>
			<td class="w-1/3">List all coin balances for the active address</td>
		</tr>
	</tbody>
</table>

## Troubleshooting

<table class="w-100">
	<thead>
		<tr>
			<td>Error or symptom</td>
			<td>Cause</td>
			<td>Fix</td>
		</tr>
	</thead>
	<tbody>
		<tr>
			<td>`Cannot find gas coin for signer address`</td>
			<td>Active address has no RTD tokens</td>
			<td>Fund the address with the faucet (Devnet/Localnet) or web faucet (Testnet)</td>
		</tr>
		<tr>
			<td>`Client/server API version mismatch`</td>
			<td>CLI version doesn't match the network's protocol version</td>
			<td>Rebuild the CLI from the reviewed RTD source revision</td>
		</tr>
		<tr>
			<td>`Your package is already published`</td>
			<td>`Published.toml` already has an entry for this environment</td>
			<td>Use `rtd client upgrade` to upgrade, or switch to a different network with `rtd client switch --env`</td>
		</tr>
		<tr>
			<td>Transaction fails with `InsufficientGas`</td>
			<td>Gas budget too low or insufficient balance</td>
			<td>Increase `--gas-budget` or fund the address. Use `--dry-run` to estimate cost first</td>
		</tr>
		<tr>
			<td>`ObjectVersionUnavailableForConsumption`</td>
			<td>Object was modified by another transaction since you last read it</td>
			<td>Re-fetch the object with `rtd client object OBJECT_ID` and retry</td>
		</tr>
		<tr>
			<td>`Package dependency cannot be found`</td>
			<td>Active network doesn't have the required dependency published</td>
			<td>Verify your environment with `rtd client active-env` and that dependencies are published on that network</td>
		</tr>
		<tr>
			<td>`rtd client faucet` fails on Testnet</td>
			<td>`rtd client faucet` only supports Devnet and Localnet</td>
			<td>Ask the operator of the configured RTD network how test gas is distributed; no public RTD faucet is verified</td>
		</tr>
	</tbody>
</table>
