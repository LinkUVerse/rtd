# RTD Full Node gRPC types

Enums, messages, and scalar field types are defined in the checked-in `temp/rtd-apis/proto/rtd/rpc/v2` tree and the imported Google protobuf definitions. The [forked RTD API proto source](https://github.com/LinkUVerse/rtd-apis/tree/main/proto/rtd/rpc/v2) is the reference until a local generator creates and validates a matching documentation artifact.

Use the [service method overview](fullnode-protocol) to identify the relevant request and response type, then read that type's `.proto` file. A type present in source does not by itself prove that a public RTD endpoint is deployed.
