Build the `rtd` CLI from the reviewed source revision with `--features tracing`. Move unit tests and transaction replay can generate trace data for debugging. Consult the CLI help for the exact commands supported by your revision:

```sh
rtd move test --help
rtd replay --help
```

A replay must use checkpoint and transaction data from the same RTD chain and a matching protocol revision. A Sui Mainnet transaction, package ID, or GraphQL endpoint cannot be used as an RTD trace source.

No separately published `linku.move-trace-debug` Marketplace extension has been verified. If you use an upstream editor extension for generic Move syntax, inspect its network calls and binary downloads and test it against RTD source before treating it as an RTD debugger. See [Move language tools](/references/ide/move).
