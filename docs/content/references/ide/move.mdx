The RTD CLI provides compiler diagnostics and Move tests for packages in this fork:

```sh
rtd move build
rtd move test
```

Run these from a package directory containing `Move.toml`. The repository also includes Move language server source. Build and configure a language server from the same source revision if your editor needs completion or navigation, then test it against RTD framework dependencies.

An upstream Sui VS Code extension may analyze generic Move syntax, but its publishing identity, binary download behavior, network URLs, and transaction tooling are not verified for RTD. No `linku.move` Marketplace listing is established by this fork. Do not present an upstream extension as an RTD release. See [Move CLI](/references/cli/move) and [trace debugging](/references/ide/debugger).
