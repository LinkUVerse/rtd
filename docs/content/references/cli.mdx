Rtd provides a command line interface (CLI) tool to interact with the Rtd network, its features, and the Move programming language. The complete suite of tools is called the Rtd CLI, with commands grouped together by feature. Each group of commands is commonly referred to by its top-level command or utility: Rtd Client CLI, Rtd Keytool CLI, Rtd Move CLI, Rtd Completion CLI, and Rtd Validator CLI.

<ImportContent source="cli-check-install" mode="snippet" />

## Update CLI

The recommended way to manage Rtd CLI installations and versions is through `suiup`: https://github.com/LinkUVerse/suiup.

:::info

The `tracing` feature is important because it adds Move test coverage and debugger support in the Rtd CLI. Unless you enable it, you cannot use these two features.

:::

## Rtd CLI commands

There are a number of top-level commands available. Use the `help` flag for the commands that are not documented yet. For example, `rtd validator --help`.

- **[Rtd Client CLI](/references/cli/client):** Use the `rtd client` commands to interact with the Rtd network.
- **[Rtd Client PTB CLI](/references/cli/ptb):** Use the `rtd client ptb` command to build and execute PTBs.
- **[Rtd Completion CLI](/references/cli/completion):** Use the `rtd completion` command to generate shell completion scripts.
- **[Rtd External Keys CLI](/references/cli/external-signers):** Use the `rtd external-keys` commands to manage keys on external hardware signers (Ledger, YubiKey).
- **[Rtd Keytool CLI](/references/cli/keytool):** Use the `rtd keytool` commands to access cryptography utilities.
- **[Rtd Move CLI](/references/cli/move):** Use the `rtd move` commands to work with the Move programming language.
- **[Rtd Replay CLI](/references/cli/replay):** Use the `rtd replay` command to replay a transaction and generate transaction traces for the Move Debugger and trace analysis tools.
- **[Rtd Validator CLI](/references/cli/validator):** Use the `rtd validator` commands to access tools useful for Rtd validators.
