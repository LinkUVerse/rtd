This fork includes GraphQL and indexer source components. A GraphQL service requires an indexer database, ingest pipeline, and an endpoint operated for the same RTD chain. No public RTD GraphQL endpoint or availability guarantee is established here.

For deployment, follow the [indexer stack guide](/operators/data-management/indexer-stack-setup) with operator supplied checkpoint and full node sources. Confirm that the GraphQL service reports data from your intended chain before using it. For the API surface, inspect the schema generated by the deployed binary and source revision; upstream Sui schema examples are not evidence of an RTD public service.
