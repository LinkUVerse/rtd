Before publishing, configure the CLI for the intended RTD network, confirm its chain identifier, and fund the publishing address with RTD from that network's genesis or operator-controlled faucet. No public RTD Devnet or Testnet faucet is verified here.

From the package directory, build and test against its configured environment, then run `rtd client publish`. Record the returned package ID and transaction digest from this RTD chain. See [local network setup](/getting-started/onboarding/local-network).
