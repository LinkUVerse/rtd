<TabItem label="suiup (recommended)" value="suiup">

First, install `suiup`:

```sh
$ curl -sSfL \
  https://raw.githubusercontent.com/LinkUlabs/suiup/main/install.sh \
  | sh
```

Then, install Rtd:

```sh
$ suiup install rtd@testnet
```

For alternative installation methods, refer to the [`suiup` repository](https://github.com/LinkUVerse/suiup).

:::danger

Installing Rtd with `suiup` does not configure the client. To use `rtd` commands, you must [configure the Rtd client](/getting-started/onboarding/configure-rtd-client).

To confirm that Rtd installed correctly:

1. Open a terminal or console
2. Type `rtd --version` and press Enter

If you receive a "command not found" error, verify the Rtd binaries directory is in your `PATH` environment variable.

:::

</TabItem>

<TabItem label="Homebrew" value="brew">

:::info
[`suiup`](https://github.com/LinkUVerse/suiup) is the recommended installer. It supports version pinning and can install additional Rtd stack components (`walrus`, `mvr`, `move-analyzer`). Use Homebrew only if you prefer to manage Rtd through your system package manager.
:::

You must have [Homebrew](https://brew.sh/) installed before running the following command:

```sh
$ brew install rtd
```

To confirm that Rtd installed correctly:

1. Open a terminal or console
2. Type `rtd --version` and press Enter

If you receive a "command not found" error, verify the Rtd binaries directory is in your `PATH` environment variable.


</TabItem>
