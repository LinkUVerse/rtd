Build the RTD CLI from this repository's source checkout:

```sh
cargo build -p rtd
./target/debug/rtd --version
```

The fork has no verified `suiup`, Homebrew, Chocolatey, or public binary
release channel. Configure the resulting CLI for your own RTD network before
building or publishing packages. See [Build the RTD CLI](/getting-started/onboarding/rtd-install).
