questions:
  - How do I start developing against RTD?
  - Is a public RTD Testnet available?
answer: >-
  Build the fork source, start a local RTD network, verify its chain ID, obtain
  gas from that network's local faucet, and publish a Move package. This guide
  does not assume a public RTD network.
---

RTD development begins with a network whose genesis and chain ID you control. No public RTD Mainnet, Testnet, Devnet, faucet, wallet service, or explorer is established by these pages.
