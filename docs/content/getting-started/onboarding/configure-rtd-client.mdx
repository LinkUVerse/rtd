First, [build the RTD CLI](/getting-started/onboarding/rtd-install) and [start a local network](/getting-started/onboarding/local-network). The CLI stores client configuration under `~/.rtd/rtd_config` by default. A different config directory can be selected through the CLI options.

```sh
rtd --version
rtd client new-env --alias localnet --rpc http://127.0.0.1:9000
rtd client switch --env localnet
rtd client active-env
rtd client chain-identifier --format hex
```

Use the actual endpoint shown by your node if it differs from the example. Record the chain ID together with the genesis file and compare it with the chain you intended to connect to. The CLI may inherit `devnet`, `testnet`, or `mainnet` aliases from upstream defaults; these aliases and their public URLs are not RTD services. Do not select them for an RTD transaction.

Run `rtd client active-address` to inspect the current address. The keystore contains signing material; protect it and any recovery phrase. Next, [create or select an address](/getting-started/onboarding/get-address) and [obtain gas on the same network](/getting-started/onboarding/get-coins).
