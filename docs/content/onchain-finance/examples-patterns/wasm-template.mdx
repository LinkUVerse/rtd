# WebAssembly bytecode templates

The upstream example edited compiled Move bytecode in a browser. This RTD checkout does not include a verified fork of its template package or WASM editing library. The inherited bytecode was built for another chain and is not a valid RTD package artifact.

If a browser-based publisher is needed, build its Move modules from source against this fork, compile the WASM tool from audited source, and verify the generated bytecode and published package on a local RTD chain before exposing it to users. For current package development, use the [Move package workflow](/develop/manage-packages/move-package-management).
