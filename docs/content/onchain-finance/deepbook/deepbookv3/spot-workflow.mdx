# Spot Trading Workflow

This page previously described an upstream Sui DeepBook workflow as if it were deployed on RTD. **It is not an operational RTD guide.** RTD has no public Mainnet, and no public RTD DeepBook Testnet is verified.

No RTD DeepBookV3 package, pool, DEEP coin, or indexer deployment has been verified. Upstream contract IDs, market state, and transaction examples are not RTD facts.

To enable this topic, first port the relevant Move contracts and SDK, deploy them to a specifically identified RTD network, and verify the package IDs, shared objects, coin types, transaction results, and indexer against that chain. Publish an RTD-specific guide only after those checks pass. See [DeepBook deployment status](/onchain-finance/deepbook) and [RTD networks](/develop/rtd-architecture/networks).
