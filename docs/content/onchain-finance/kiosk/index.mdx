The RTD framework source contains `kiosk.move` and `kiosk_extension.move`, plus
Move tests for their core behavior. These modules can support commerce patterns
on an RTD network that deploys the matching framework.

No public RTD Kiosk marketplace, hosted app, or third-party integration has been
verified. The child pages retain inherited design guidance; review package IDs,
SDK examples, and actual transactions on your own RTD chain before use.
