# Permissioned Assets Actions

The Permissioned Asset Standard (PAS) described by the upstream Sui documentation has not been ported or deployed as an RTD package in this source fork. This repository does not contain the PAS Move package or a PAS TypeScript SDK. Upstream package IDs, npm packages, object models, and integration steps are not RTD deployments.

A future RTD integration requires the contracts and SDK to be ported, built, deployed to an identified RTD network, and tested with real transactions before an operator publishes addresses or instructions. See [RTD networks](/develop/rtd-architecture/networks) and [asset custody](/onchain-finance/asset-custody/wallets).
