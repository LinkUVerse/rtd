SuiLink is an upstream Sui service. No RTD wallet-linking package, service, Mainnet or Testnet deployment, cross-chain verification flow, or NFT contract has been verified. The upstream SuiLink site and package IDs must not be used as RTD endpoints or contract identifiers.

An RTD wallet-linking feature would need a separately deployed contract on an identified RTD chain, signed proofs for each external chain, and verification tests that bind all addresses to that chain. See [wallets](/onchain-finance/asset-custody/wallets) and [RTD networks](/develop/rtd-architecture/networks).
