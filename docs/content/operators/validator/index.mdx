Rtd uses a delegated proof-of-stake model where validators process transactions and maintain network consensus. These guides cover validator configuration, committee management, rewards, and operational practices for a network you operate. RTD has no launched public Mainnet validator set; obtain the approved genesis and committee details from your network operator.
