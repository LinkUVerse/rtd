# 092c2389：保留 borrow graph overflow root borrows

## 基线关联

fork 基线假定 local root 不会出现 full borrow；大 enum pattern 会触发 borrow graph overflow optimization，使编译器在该断言处 panic。

## 移植与验证

新增上游 Move regression 和 snapshot。临时包修复前 panic 于 `state.rs:385`；修复后正常返回 borrow diagnostics，不再 panic。

```text
target/debug/rtd move build --path <regression> --environment testnet
before: assertion failed: full_borrows.is_empty()
after: ordinary E07006/E07004 diagnostics, no panic

cargo check -p rtd --bin rtd
Finished successfully
```
