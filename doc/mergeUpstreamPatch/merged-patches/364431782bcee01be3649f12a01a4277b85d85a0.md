## 基线关联

fork 基线在 bitmap 反序列化后、去重迭代前没有 cardinality 上限，会按攻击者输入扩大 CPU 与内存；legacy multisig 转换也先把整个 bitmap 收集为 `Vec`，再拒绝越界索引。

## 移植与验证

在任何迭代/二次分配前按既有 `MAX_VALIDATOR_COUNT = 150` 拒绝超限 bitmap；legacy 转换改为直接消费 iterator、遇到非法索引立即失败。新增 cardinality 151 回归测试。

```text
cargo test -p rtd-types bitmap --lib
4 passed; 0 failed

cargo check -p rtd-types
Finished successfully
```
