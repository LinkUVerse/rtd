## 基线关联

fork 基线用进程级递增计数器分配未发布包的 dummy address。同一包图重复加载会得到不同 named addresses，使 analyzer 和缓存结果不确定。

## 移植与验证

以 pinned dependency 的稳定 TOML 表示计算 SHA-256，并按包名稳定构造 linkage。回归测试先观察到两次加载地址从 `0x1002/0x1003` 漂移到 `0x1005/0x1006`，实现后通过：

```text
cargo test --manifest-path external-crates/move/Cargo.toml -p move-package-alt test_dummy_addr_determinism --lib
1 passed; 0 failed
```

完整 crate 测试另有 1 个既有 RTD lockfile key 排序期望失败，与本补丁无关。
