# 84ae728b：不读取已 prune 的旧 accumulator objects

- 上游提交：`84ae728bdc5b6c096fb8ee802f96e0ebc4f32025`
- RTD 提交：`7647f416fee43c299d02d17cda5cc9d8edd7b8b7`

## 基线关联

eager withdrawal scheduler 按旧 root version 读取 child accumulator object；pruning 或 Tidehunter 不保证该旧版本仍可用。缺失对象时还无法判断零余额对应哪个 root version。

## 移植与验证

execution cache 新增无竞态的最新余额与 root version 读取；account state 记录 settled version，忽略旧 settlement 和已过期 withdrawal。补丁按 RTD 品牌机械映射，16 个文件 dry-run 全部匹配。
