# 774bd6ba：正确处理 tonic IPv6 peer URI

- 上游提交：`774bd6baf7e63e2eb1f789cd987a5dd90bafd334`
- RTD 提交：`446f281946463bc164e3bf9d5470b7d8ac5f4b5e`

## 基线关联

fork 基线把 IPv6 与 UDP port 直接拼为 `2001:db8::1:8080`，缺少 URI authority 所需方括号；`Channel::from_shared` 遇到该无效 URI 还会 unwrap panic。

## 移植与验证

IPv6 分支使用 `SocketAddrV6` 得到 `[2001:db8::1]:8080`，endpoint 解析错误映射为 `ConsensusError::NetworkConfig`。新增 IPv6 格式回归测试，修复前实际得到无方括号字符串。
