# e0006bcc：补齐 address-balance affected addresses

- 上游提交：`e0006bcc54c747977437c29ef5846373cb871fd0`
- RTD 提交：`bc0cec63adec8f3c3f762ad9f83b3f9751ccf888`
- 上游标题：`[indexer-alt] include address balance addresses in tx_affected_addresses (#24799)`

## 基线关联

fork 基线已有 address-balance accumulator events，也已有 `tx_affected_addresses` pipeline，但该 pipeline 只收集对象 owner、sender 和 gas payer。余额只通过 accumulator write 改变时，受影响地址不会进入过滤索引，按 affected address 查询会漏交易。

## 移植内容

- 从 effects accumulator events 中筛选 `Balance<T>` 且值为 integer 的 write。
- 将其 address 与对象 recipients、sender、payer 合并去重。
- 增加只构造 checkpoint/effects、无需 PostgreSQL 的 processor 回归测试。

## 红绿验证

修复前测试在 affected address 断言失败。修复后：

```text

1 passed; 0 failed
```
