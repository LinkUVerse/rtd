## 基线关联

基线把 ephemeral pubfile 的 local/root dependency 写成相对路径。pubfile 从另一个包目录加载时，相同文本会解析到不同包并静默失配。

## 移植与验证

新增独立 `EphemeralDependencyInfo`，本地和 root pin 统一规范化为绝对 `local` 路径；测试在 macOS 上额外 canonicalize `/var` 到 `/private/var`。

```text
cargo test --manifest-path external-crates/move/Cargo.toml -p move-package-alt ephemeral_ --lib
14 passed; 0 failed
cargo test --manifest-path external-crates/move/Cargo.toml -p move-package-alt parse_render_publocal --lib
1 passed; 0 failed
```
