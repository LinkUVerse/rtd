## 基线关联

fork 基线在 `AuthorityPerEpochStore` 构造阶段直接拒绝非 `ExecutionTimeEstimate` congestion mode。replay 需要读取使用旧 mode 的历史 epoch，因此会在启动 validator-only 组件之前被错误终止。

## 移植与验证

epoch store 对历史 mode 使用默认 estimator 参数；严格断言移到只由 validator 构造的 `ConsensusHandler`，因此不会放宽 validator 运行约束。
