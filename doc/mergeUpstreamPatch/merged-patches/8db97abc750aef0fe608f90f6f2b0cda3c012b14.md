## 基线关联

fork 基线的签名验证结果依赖当前 address aliases，却只用 signed data 作为缓存键；alias object 更新后可能复用旧验证结果。

## 移植与验证

把 signer alias versions 序列化进 cache digest，并新增不同 alias version 产生不同 digest 的回归测试。
