## 基线关联

fork 基线 Move decompiler 假设 structuring 完成后不会残留 `Jump`/`JumpIf`，并假设 loop successor 必然已经结构化。不可约或暂不支持的 CFG 会命中 `unreachable!`/`panic!`，使整个 module 反编译失败。

## 移植与验证

完整移植五文件支撑链：新增 `Unstructured` AST 与 goto nodes、两套打印支持、refinement 递归、loop successor 非 panic fallback，以及残留条件/无条件 jump 转换。输出用于可读诊断，不保证可重新编译。

```text
cargo test --manifest-path external-crates/move/crates/move-decompiler/Cargo.toml --lib
3 passed; 0 failed

cargo check --manifest-path external-crates/move/crates/move-decompiler/Cargo.toml
Finished successfully
```

验证时为仓库中命名损坏的嵌套 Move test targets 临时补充 `path`；测试后已撤销这些非补丁改动。
