# f55e9510：允许 spec 作为普通变量名

- 上游提交：`f55e95101969828318bdc1a171ab677c7701d746`

## 基线关联

fork 基线的 Move tree-sitter grammar 把历史 contextual keyword `spec` 作为全局关键字，高亮规则也将其固定标为 keyword。因此参数、局部变量和普通调用位置使用 `spec` 时 parser 会产生 error node。

## 移植内容

- 让 `spec` 通过 reserved identifier 只在 spec block 语境消歧。
- 从 keyword highlight 列表移除 `spec`。
- 使用 tree-sitter CLI 0.25.8、ABI 14 重建 `grammar.json` 和 `parser.c`；生成物与上游提交逐字节一致。
- 增加包含参数、局部变量和调用参数的复现 fixture。

修复前：

```text
tests/spec_non_kw.move (ERROR [3, 9] - [3, 13])
```

修复后目标 fixture 和全部现有 fixtures 均以 exit 0 完成解析。
