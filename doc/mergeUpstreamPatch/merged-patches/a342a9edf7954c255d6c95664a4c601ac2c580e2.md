- 上游标题：`jsonrpc-alt: catch panic handler`

## 基线关联

fork 基线和 RTD 的 indexer-alt JSON-RPC server 没有 HTTP panic middleware。在 unwind 构建中请求连接会异常结束；在默认 abort release 构建中则可终止服务进程。

## 移植内容

- JSON-RPC HTTP middleware 捕获 panic，并返回标准 `jsonrpc: 2.0`、internal error code 和 panic context。
- 增加 `jsonrpc_requests_panicked` 指标。
- Docker 使用共用的 `release-unwind` profile 及正确的 profile 产物路径。
- 增加会 panic 的测试 RPC method 和真实 HTTP 回归测试。

## 红绿验证
