# 5328c889：保留 remote checkpoint bucket 子路径

- 上游提交：`5328c8890193d199a6e4923b4f4c409fcfe7d2d4`
- RTD 提交：`876bf74a991b5a02af0426701f65e7d38fa65bcd`

## 基线关联

fork 基线的 remote ingestion 对 `epochs.json` 和 checkpoint 文件调用 `Url::join` 时使用以 `/` 开头的路径。RFC 3986 会把它解释为 host-root 绝对路径，导致类似 `https://host/checkpoint-bucket/` 的 bucket 子路径被删除并返回 404。

## 移植与验证

两个资源名改为相对路径；新增 wiremock 回归测试同时验证 `/bucket/epochs.json` 和 `/bucket/42.chk`。测试在修复前得到 404，修复后通过。

```text
cargo test -p rtd-indexer-alt-framework remote_client::tests --lib
6 passed; 0 failed
```
