## 基线关联

fork 基线的 VS Code formatter 对共享 worker 使用 `once('message')`。多个文件同时 format-on-save 时，所有等待者都可能消费最先返回的文档内容并把它写入错误文件。此前已移植的 `spec` identifier grammar 也尚未更新 prettier plugin 内置 WASM。

## 移植与验证

请求和响应携带 document URI，每个 listener 只接受对应文档；同时更新 extension/plugin 版本和 bundled tree-sitter WASM。上游 changelog 删除及整文件 JSON 空白变化未移植。
