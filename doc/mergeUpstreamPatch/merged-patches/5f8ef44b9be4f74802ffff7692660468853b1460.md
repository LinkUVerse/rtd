## 基线关联

fork 基线的 package compiler 把 `BUILDING` 等日志写到 stdout，`rtd client publish --json` 因此输出混合文本而不是合法 JSON。

## 移植与验证

compiler writer 改为 stderr。上游原回归用例依赖 fork 后新增、已排除的 ephemeral package fixture，因此用基线已有 `ptb_publish/test_pkg` 构造等价 dry-run JSON 测试。修复前 `jq` 以 invalid numeric literal 失败，修复后通过；相关 publish 脚本按上游方式同时捕获 stdout/stderr。

```text
cargo test -p rtd --test shell_tests -- publish_json
1 passed; 0 failed

cargo test -p rtd --test shell_tests -- publish_valid
```
