# 3e497b2a：保留嵌套 ingestion CLI 参数

## 基线关联

indexer framework 的 nested Clap 参数没有继续 flatten `ClientArgs`，因此 ingestion endpoint 等选项在结构体中存在但不能从 CLI 解析。

## 移植与验证

补齐 nested flatten 并增加实际命令行解析测试：

```text
cargo test -p rtd-indexer-alt-framework test_client_args_are_parsed_from_cli --lib
1 passed; 0 failed
```
