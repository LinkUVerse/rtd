# e59d192e：custom clients 使用 genesis committee

- 上游提交：`e59d192e74d2ec990226bad8cf86fc76ac272073`
- RTD 提交：`e5f0991d7eb7e442e6fac4f1e792177715669691`

## 基线关联

fork 基线的 `build_custom_clients` 在未注入 CommitteeStore 时使用当前 committee 初始化 store；恢复到非 genesis epoch 时会缺少从 epoch 0 开始的 committee 链。

## 移植与验证

让 custom-client builder 显式接收 genesis committee，并更新所有 RTD 调用方；新增 current committee 为 epoch 1 时 store 仍从 epoch 0 初始化的回归测试。
