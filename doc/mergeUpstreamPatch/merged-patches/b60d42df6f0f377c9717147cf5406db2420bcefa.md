# b60d42df：限制 gRPC batch 请求大小

- 上游提交：`b60d42df6f0f377c9717147cf5406db2420bcefa`
- RTD 提交：`96a5d8c994007931a059a629cf8767fb46a392fb`

## 基线关联

fork 基线的 ledger 和 KV RPC batch handlers 对输入数量均无限制，可在解析或存储访问前消耗任意资源。

## 移植与验证

objects 上限 1000，transactions 上限 200；超限统一返回 `InvalidArgument`。边界测试确认 limit 本身允许、limit+1 拒绝。

```text
cargo test -p rtd-rpc-api batch_size_limit_is_inclusive --lib
1 passed; 0 failed

cargo check -p rtd-kv-rpc
Finished successfully
```
