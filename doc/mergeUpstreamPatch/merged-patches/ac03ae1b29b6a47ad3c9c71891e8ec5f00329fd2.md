# ac03ae1b：修正 stackless 位运算结果类型

## 基线关联

`BitAnd`、`BitOr`、`Xor` 被翻译为 `bool` 结果，即使输入和 Move 语义都是整数。错误类型会传播到 stackless IR 的后续分析。

## 红绿验证

先更新 bit-ops snapshots，旧 translator 产生 `expected u8, got bool` 的 snapshot mismatch；改为沿用左操作数类型后：

```text
cargo test --manifest-path external-crates/move/Cargo.toml -p move-stackless-bytecode-2 --test from_source bit_ops
1 passed; 0 failed
```
