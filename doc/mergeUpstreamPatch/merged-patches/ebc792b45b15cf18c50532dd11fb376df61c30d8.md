# ebc792b4：限制索引分页游标范围

- 上游提交：`ebc792b45b15cf18c50532dd11fb376df61c30d8`
- RTD 提交：`ff9a47210d367e7dc887bd669bb907a478950ba3`
- 上游标题：`graphql: clamp indices for pagination (#24785)`

## 基线关联

fork 基线和 RTD 的 `Page<JsonCursor<usize>>::paginate_indices` 都直接使用 `after + 1` 和 `before` 作为序列索引，只限制页大小而不限制索引上界。游标大于实际序列长度时，分页仍会调用 `node(index)`；对数组/向量消费者会造成越界 panic，而正确结果应为空 connection。

## 移植内容

- 将计算出的 `lo` 和 `hi` 都限制在 `total` 以内。
- 增加直接单测，使用长度 3 的序列和 1000/2000 越界游标，验证结果为空且不会调用越界索引。
- 路径和 GraphQL crate 名使用 RTD 品牌映射。
