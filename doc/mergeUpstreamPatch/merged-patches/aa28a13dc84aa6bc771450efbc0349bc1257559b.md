## 基线关联

fork 基线 GraphQL 配置仍登记 `txBytes` 和 `verifyZkloginSignature`，实际 schema 已使用 `transactionDataBcs` 与 `verifyZkLoginSignature`。这些变量因此未被归入 transaction payload budget，合法的大交易、签名或 zkLogin message 会错误套用较小的普通 query limit。

## 移植与验证

仅修正三个参数名，并新增配置与 schema 一致性单测；不移植上游 E2E helper 清理。

```text
cargo test -p rtd-indexer-alt-graphql transaction_payload_arguments_match_schema --lib
1 passed; 0 failed
```
