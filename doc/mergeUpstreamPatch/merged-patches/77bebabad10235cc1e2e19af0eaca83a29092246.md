# 77bebaba：crash recovery 保留持久化 state hash

- 上游提交：`77bebabad10235cc1e2e19af0eaca83a29092246`

## 基线关联

fork 基线只按 highest executed checkpoint 清理 state hashes。若进程在 builder summary 持久化后、executed watermark 前崩溃，恢复会删除已经认证且后续仍需使用的 hash，导致 ECMH 分叉。

## 移植与验证

清理边界改为 persisted builder summary 与 highest executed checkpoint 的最大值，并新增 crash-window 回归测试。

```text
cargo test -p rtd-core state_hash_cleanup_preserves_persisted_builder_checkpoint --lib
1 passed; 0 failed
```
