# 6023ccd1：修复 VecPopBack pretty-printer 越界

- 上游提交：`6023ccd1db7b147211eefeea1172c06dd42d6523`
- RTD 提交：`299e025219cc53d2d725cc0b9c2b7975ede24d89`

## 基线关联

fork 基线 Move decompiler 把一元 `VecPopBack` 当成二元操作，pretty-printer 读取不存在的 `args[1]`，可在反编译合法 bytecode 时越界 panic。

## 移植与验证

输出改为 `vector.pop_back()` 并新增直接单元测试。

```text
cargo test --manifest-path external-crates/move/crates/move-decompiler/Cargo.toml vec_pop_back_uses_its_single_argument --lib
1 passed; 0 failed
```

验证时为仓库中命名损坏的嵌套 Move test targets 临时补充 `path`；测试后已撤销这些非补丁改动。
