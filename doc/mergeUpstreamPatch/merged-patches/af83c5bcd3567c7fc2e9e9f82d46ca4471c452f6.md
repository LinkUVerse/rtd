# af83c5bc：拒绝 balance index 尚未追上的读取

- 上游标题：`Handle unindexed balance_changes (#24794)`

## 基线关联

fork 基线的 gRPC reader 可以先从执行存储读到 checkpoint 或 transaction，但 `balance_changes` 由异步索引生成。索引 watermark 尚未追上时，旧代码会把缺失索引误当成空余额变化，Rosetta 等调用方因此得到错误数据。

## 移植内容

- checkpoint 响应先比较请求序号与 reader latest checkpoint，未索引时返回 `CheckpointNotFound`。
- 单笔 transaction 先读取其 checkpoint 并比较 watermark，缺失或超前时返回 `TransactionNotFound`。
- batch transaction 对每笔执行同一检查，并保留逐项 error response 语义。
