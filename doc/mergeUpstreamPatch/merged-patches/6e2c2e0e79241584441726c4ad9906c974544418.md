# 6e2c2e0e：分离 object funds settlement 与 commitment

- 上游提交：`6e2c2e0e79241584441726c4ad9906c974544418`
- RTD 提交：`0b1eb0340e4f479a9893e9ba01c1f51a851583bd`

## 基线关联

fork 基线 object-funds scheduler 在看到较新 accumulator version 时清空全部 pending withdraws，并假设 schedule version 单调递增。不同账户交易可乱序执行，settlement 也可先于旧 withdraw，导致未进入 checkpoint 的 reservation 被提前丢弃。

## 移植与验证

RTD 保留现有 scheduler 架构，按 account 和 accumulator version 分别记录 pending withdraws；settlement 只通知 waiter，checkpoint executor 从 committed effects 的 accumulator-root input version 精确清理对应 reservation。新增乱序 schedule 和按版本 commitment 清理测试。
