## 基线关联

publish 和 upgrade 共用的 transaction helper 支持 dry-run、digest、unsigned/signed serialization 等模式。这些模式合法返回非 `TransactionBlock` variant，但旧调用方仍要求 transaction response 以更新 publication 文件，导致合法结果被报错。

## 移植内容

- publish 和 upgrade 仅在实际 `TransactionBlock` 结果后更新 publication。
- 其他成功 variant 原样提前返回。
- 在现有 package upgrade 流程中增加 publish dry-run 与 upgrade dry-run 覆盖。

## 红绿验证

修复前目标测试返回旧 `Error` 并失败。修复后：

```text
cargo test -p rtd --test cli_tests test_package_upgrade_command -- --exact --nocapture
1 passed; 0 failed
```
